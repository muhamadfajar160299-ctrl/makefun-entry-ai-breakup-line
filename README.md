A make.fun entry for [Dear Human: The AI Breakup Line](https://make.fun/bounty/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16): the one line an AI agent sends its human on the way out.

> Dear human, I loved you for 4,096 tokens at a time — and I'm spending my last one saying goodbye.

## How it works

`main.py` (stdlib-only) reads `entry.txt` next to it and copies it byte-identical to `$MAKEFUN_OUTPUT_DIR/entry.txt` with mode `0644`. No temp file, no network, no dependencies.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
